NotchQuota 0.1.13：可自由摆放的侧边栏模式。

在“设置与更新”选择“侧边栏模式”。52 点宽侧栏固定排列勾选账号，显示头像、额度环和百分比。悬停展开详情，点击固定，再次点击取消。可自由拖动，靠近屏幕边缘才吸附，并保存位置。

鼠标离开 3 秒后收成小胶囊，贴边时收成窄把手；移入弹性展开，固定详情时保持展开，也可关闭自动收缩。墨蓝石墨渐变、淡蓝悬停高光、轻微弹性与一次性眨眼均为原生图层效果，静置后停止；减少动态效果和低电量模式关闭动画。额度保留绿色、黄色、红色。

侧栏不自动轮换，不因悬停发起查询，与其他模式共用缓存与刷新任务。保留原有灵动岛、菜单栏、账号选择、临时隐藏和恢复入口。

本机测试系统为 macOS 26.5.2；macOS 27 仍需真机验收。
