NotchQuota 0.1.2：更清晰、缓慢呼吸的刘海额度灯。

- 颜色更鲜明，2.1 点额度线带轻微柔光，约 4.8 秒完成一次明暗呼吸。
- 单个系统透明度动画，无逐帧轮询；展开、屏幕休眠、低电量及减少动态效果时停止呼吸。
- 保留 Codex → Claude → Antigravity 的安装优先级、16 点图标、15 秒收起和 3 分钟刷新。

适用于 Apple Silicon / macOS 13+。安装包经 Developer ID 签名和 Apple 公证，拖入 Applications 替换旧版即可。读取额度需要原应用已有有效登录。不同机型和系统的耗电表现仍需长期验证。
