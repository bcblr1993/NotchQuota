NotchQuota 0.1.13：可自由摆放的侧边栏模式。

在“设置与更新”选择“侧边栏模式”。52 点宽侧栏固定排列勾选账号，显示头像、额度环和百分比。悬停展开详情，点击固定，再次点击取消。可自由拖动，靠近屏幕边缘才吸附，并保存位置和所在屏幕。鼠标或窗口焦点跨屏不会让侧栏跳屏，主动拖动才换屏；原屏幕断开时回退到可用屏幕。

鼠标离开 3 秒后收成可选外观（原生胶囊、磨砂圆球、迷你仪表、小幽灵），贴边时小幽灵倾斜探头、露出约半个身体（无小手），其他样式完整显示静止图标；鼠标移入立即展开账号面板，固定详情时保持展开，也可关闭自动收缩。墨蓝石墨渐变、淡蓝悬停高光、轻微弹性均为原生图层效果，静止图标不浮动或眨眼，隐藏和休眠后停止；减少动态效果和低电量模式关闭动画。额度保留绿色、黄色、红色。

侧栏不自动轮换，不因悬停发起查询，与其他模式共用缓存与刷新任务。保留原有灵动岛、菜单栏、账号选择、临时隐藏和恢复入口。

修复详情切换时标题裁切、面板高度异常、箭头错位，以及账号悬浮提示遮挡内容；详情使用可取消的淡入淡出。

验证：38 项单元测试、79 条侧栏检查输出（含完成标记）和原有 UI 回归通过；新增四种外观左右贴边、移入立即展开与隐藏停止动画检查，并检查实际渲染。此前完成的跨屏定位验证保留，四种外观尚未逐一测量 GPU 与帧率。

本机测试系统为 macOS 26.5.2；macOS 27 仍需真机验收。Instruments 轨迹保存异常，逐帧流畅度尚未完成测量。
