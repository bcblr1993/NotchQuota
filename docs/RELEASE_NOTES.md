NotchQuota 0.1.9：Antigravity 多实例与账号头像。

单实例用户保持原有体验。额外实例默认不启用，可在右键“Antigravity 多实例”分别勾选；多账号使用头像或编号区分，支持本机别名。无法自动识别时可在“账号设置”选择实例应用及受支持的登录 JSON 文件。

每个实例独立读取、续期和缓存。更换账号后清除旧头像/额度，重新勾选确认后恢复。只选一个不轮换，未选的不查询；全部隐藏后可通过菜单栏设置图标恢复。保留旧版应用选择、自动轮换和开机启动偏好。

支持范围为当前已验证的官方实例、独立副本及手动 JSON 登录来源；未支持的第三方加密/数据库格式不会猜测读取。头像及名字仅在内存缓存，绑定标识与设置保存在本机。
