# 0.1.0 验证记录

日期：2026-09-09。

已完成：

- Apple Silicon 原生 release 构建，arm64 Mach-O；包内图标资源独立于源码/构建目录。
- Swift Package 的 3 个 XCTest 用例通过，覆盖额度解析、真实零值/未知字段、颜色阈值、15 秒计时、周期识别及服务地址白名单。
- 原生 `--ui-smoke`：实际窗口闲置 15 秒隐藏，退出再进入顶部热点后显示，全部通过；截图已检查。
- 本机刘海屏紧凑尺寸 279×32 点，其中摄像头留白约 185 点，新增两侧占用约 94 点。
- Codex、Claude 桌面会话和 Antigravity 钥匙串的真实查询均成功，未使用本机运行中应用的额度接口。三个原应用无需为请求保持运行。
- 使用正常系统代理；无浏览器后台、无第三方运行时依赖。
- Developer ID 签名、Apple notarization `Accepted`、DMG staple 和票据校验通过。
- 挂载分发 DMG 后，包内应用识别为 `Notarized Developer ID`；从挂载包执行三个提供商的查询均成功。
- 本机实际安装到 Applications。交互验证了图标从 Codex → Claude → Antigravity 切换。
- 安装包约 0.84 MiB，应用约 0.88 MiB。原型稳定空闲采样 CPU 为 0.0%、RSS 约 57 MiB；不同系统和网络阶段会波动。
- GitHub macOS CI 曾发现 Swift 并发闭包的兼容性错误；修复后以发布提交的 CI 结果为准，运行记录见仓库 Actions。

未完成的覆盖，不能宣称已通过：

- 所有 M 系列机型、所有受支持 macOS 版本与全部账户类型的独立实机矩阵。
- 为了不中断用户当前工作，没有退出本机正在使用的三个原应用；独立读取由无进程依赖的实现与直接远程请求验证。
- 当前验证机的 Gatekeeper 存在 `security disabled` 本机覆盖；来源、公证和签名均已识别，但这不等同于全新默认安全策略机器的首次安装验证。
- 长期运行、多次睡眠/唤醒、显示器热插拔以及失效登录的全场景验证。

公开 Issue 可追踪以上兼容性覆盖；不要上传未经脱敏的认证日志。
