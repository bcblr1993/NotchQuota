# NotchQuota 动画与性能验证 · 2026-09-09

结论：功能回归通过，常驻资源占用低；两次动画压力采集都出现目标应用的卡顿记录，流畅度仍待优化。本轮未加入呼吸灯，也未替换本机 0.1.6 安装版。

## 已完成

- Swift 单元测试 9 项、原生 UI smoke 22 项通过；arm64 构建及发布布局检查通过。
- 新增完整动画场景 37 项检查通过，实际三次轮换间隔约 60.44 / 59.87 / 59.84 秒（含 0.25 秒观察精度和定时器容差）。
- 覆盖 12 轮展开/切换/收起、动画中模拟额度到达、16 次快速反向操作、交互暂停、模拟休眠恢复、减少动态效果路径、单应用和空安装。
- 新增轨迹统计脚本与解析回归检查：按目标 PID 过滤，解析 XML 引用，缺少应用更新数据判定为无法下结论。

测试使用本机构建的模拟数据应用，运行与安装版相同的动画路径。没有访问账户或发起额度请求。采样期间可见窗口位于本机刘海，多显示器及其他应用保持原状。

第一轮应用更新耗时中位数 1.54 ms、P95 3.35 ms、P99 5.81 ms、最大 35.55 ms；工具对 3 条卡顿给出 Potentially expensive app update(s) 提示。该提示仅是排查线索，未定位根因。两轮并非受控性能对照，不计算优化幅度或通用掉帧率。

Core Animation FPS 工具实际报错：macOS does not have an FPS metric for Core Animation。不能据此提供 FPS 数字。Animation Hitches 提供了目标 PID 的记录，因此可以确认本次压力场景有卡顿；不能把桌面总帧数当作应用 FPS，也不能将卡顿事件数直接除以更新数当掉帧率。

## 安装版资源采样

4 分钟、10 秒间隔：平均单核 CPU 0.00120%，区间最大 0.00979%；physical footprint 28.14 → 28.50 MiB，结束 RSS 65 MiB，空闲唤醒约 0.00417 次/秒。未触发既定 CPU/内存调查阈值。

采样与模拟界面测试在同一机器上进行，不是严格无干扰基准；这些数字只针对安装版进程，不包括 WindowServer/GPU 或整个测试工具开销。此次没有测量实际电池耗电，也没有执行真实睡眠/唤醒或覆盖所有屏幕刷新率。模拟额度到达只验证界面更新，不代替在线网络端到端验收。
