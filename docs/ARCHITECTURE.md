# 架构

单个 Swift Package 可执行目标 `NotchQuota`，无第三方包依赖。

- `main.swift`：应用生命周期、屏幕定位、15 秒单次定时器、热点唤出、三分钟刷新与菜单。
- `Interface.swift`：AppKit 绘制、原生图标按钮、窗口展开与额度颜色。
- `Quota.swift`：提供商模型与纯解析函数；严格区分未知、零值和满额。
- `Readers.swift`：并发隔离的读取器、网络错误、登录续期和提供商请求。
- `DesktopCredentials.swift`：只读 Claude 指定 Cookie，系统钥匙串解密。
- `GoogleCredentials.swift`：读取 Antigravity 当前钥匙串并解析安装包的 OAuth 客户端配置。
- `CodexSession.swift`：仅令牌过期时启动短时官方后台组件；不创建任务、不调用模型。
- `Installation.swift`：当前用户安装目录及 Launch Services 发现，Google 地址白名单。
- `ResourceLocator.swift`：打包后的图标定位，避免依赖开发机的 `.build` 路径。

## 生命周期

启动后显示默认应用的紧凑窗口 → 交互重置单次 15 秒定时器 → 无操作收起详情并回到默认应用，紧凑窗口始终可见。默认优先级为 Codex → Claude → Antigravity；没有安装应用时隐藏。后台查询只更新数据，不展开详情或重置计时。空闲后停止交互定时器，无轮询鼠标定时器、额度线或呼吸动画。

额度请求在后台执行，已有读数即时用于切换。读取失败时保留上次快照并显示过期状态；应用退出后快照不落盘。未知数据不推导为满额。

有刘海时使用 `safeAreaInsets` 和屏幕两侧安全区域计算摄像头留白；只在两侧额外占用约 94 点。普通显示器紧凑窗口约 100×28 点。展开宽度至少 276 点，最多显示 6 个额度窗口。

## 兼容维护

先使用脱敏 JSON 固定住新接口结构，再修改纯解析器并添加回归测试。认证错误、网页验证、额度解析失败和网络错误应当分别显示，不通过读取旧磁盘账号或其他组织静默掩盖失败。

新 Antigravity 服务地址必须经审核再加入白名单。不得为“看起来能用”而回退到不同服务环境，因为不同环境可能都返回 200，但返回不同额度池。
