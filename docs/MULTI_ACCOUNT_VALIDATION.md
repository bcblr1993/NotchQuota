# 0.1.9 多实例验证

2026-09-12，Apple Silicon 本机，三个 Antigravity 2.12.2 独立应用。

## 功能与数据隔离

- 自动发现默认应用及两个独立副本；副本通过各自后台程序与登录文件名唯一匹配，默认不启用。
- 原生菜单实际启用 Second、Third，分别显示头像、名称和各自额度。三个 Google 账号标识不同；两个显示名相同也没有串号。
- 更新保留旧版主应用选择、自动轮换及开机启动；启用两个副本后重启，选择和三份绑定保留。测试结束恢复原显示偏好，额外实例保留为手动启用。
- 手动来源使用本地应用与受支持 JSON 路径，源码不写死 Second/Third 文件名；缺失、歧义和未知存储不猜测读取。
- 账号绑定先验证身份，再查询项目/额度；换号会清除旧数据、暂停显示，重新勾选确认。单元测试覆盖相同显示名、不同身份、换号时不查询新账号额度，以及一个实例身份失效不影响另一个。

## 验证命令

- `swift test`：16 项通过。包括分离读取器、防串号、登录格式、头像来源限制、设置持久化以及原有回归。
- `scripts/build-app.sh` / `scripts/check-release.sh`：Apple Silicon 构建和嵌套签名验证通过。
- `--ui-smoke`：34 项，覆盖原有紧凑显示、15 秒收起、轮换，以及额外实例默认隐藏、独立选择、独立缓存、只显示额外实例和全部隐藏后的原生菜单栏恢复菜单。窗口仍为 279 × 32 pt。
- `--verify-accounts --force-refresh`：使用正式实现读取三个实例，三个账号的续期、身份、额度和头像解码全部通过，3 个不同身份。命令不打印邮箱、账号标识或令牌，不写回登录文件。

## 真实测试范围与限制

- 本机用原生菜单完成启用和逐账号切换，真实头像可见。重启验证已完成；未退出或修改用户正在使用的三个 Antigravity 实例。
- 查询与续期直接请求 Google 服务，不通过实例进程通信；这不等同于已经实测退出原应用后的长期运行。
- 全部隐藏时，进程继续运行；UI smoke 验证原生 NSStatusItem 已绑定包含恢复动作的菜单。Computer Use 对无窗口的应用获取状态超时，未完成该状态下的真实鼠标点击验收，不能将其写为已通过。
- 有一轮 UI smoke 与真实界面操作同时运行时，三个空闲计时断言失败；停止并行界面操作后，同一构建独立重跑通过。后续应将实际 UI 操作与 smoke 串行执行。
- 首次 30 秒空闲采样 CPU 显示 0.0%，累计 CPU 时间未增长，RSS 63.12 MiB 保持不变；这是短时观察，不能保证长期内存、能耗或稳定满帧。未恢复持续性能监控。
- 手动选择器尚未在所有第三方多开工具的存储格式上验证；当前明确支持官方来源、已验证副本及手动指定的 token JSON，不宣称兼容全部多开工具。
- 当前机器存在既有 Gatekeeper 策略覆盖，Developer ID 签名、公证与票据验证不能替代默认策略的干净机器离线安装验收。
